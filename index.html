How a curve becomes sound

Each curve is an oscillator. The highlighted wave window of the graph is looped hundreds of times per second, so its shape is literally the waveform you hear. The window slides along x during the sweep, so the timbre changes with the shape under the playhead.

If the window holds 3 bumps you hear 3× the pitch. Jumps and corners sound buzzy, smooth curves sound soft, noise() is a hi-hat.

Pitch: "Key note" plays the chord progression, "Follow curve" picks the note from f at the playhead. Click the color dot to mute.

t is time in seconds, so moving curves morph the sound. Use ^ for powers, 2x works, φ(x) = … names a curve.
